# Security Policy

This project may process financial records and personal information. Do not publish bank statements, payment-provider exports, customer details, account identifiers, credentials, or exploit details in public issues or pull requests.

Use GitHub's Security tab and **Report a vulnerability** flow for private disclosure when enabled. If unavailable, contact the repository owner privately through their GitHub profile and request a secure route. Do not publish details while arranging contact.

Include the affected commit/version, exact component, a minimal synthetic reproduction, demonstrated impact, and redacted logs. Never attach real payment records or live credentials.

This tool is an analysis aid, not a payment processor or accounting authority. A detected match does not establish final settlement. A reconciliation result must be reviewed against authoritative records before operational or accounting decisions.
